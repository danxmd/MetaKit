# Spec Delta

## ADDED Requirements

### Requirement: Try it is remembered
The Build view SHALL remember in the browser whether the **Try it** preview is open, and SHALL open the next Kit with the preview shown or hidden the same way.

#### Scenario: Closed stays closed
- **WHEN** the person closes **Try it**, goes back to the Kits page and opens a Kit again
- **THEN** the preview is closed and the **Try it** button is not pressed
