# Topic list (master)

Every id below is a topic file `packages/docs/content/<category>/<id>.md`. Anyone may link to any id with `[[id]]`. The owner writes the file. Add further topics inside your own area when a function needs one; do not reuse another owner's id.

Front matter of every file:

```
---
id: classes
title: Classes
category: build
summary: One sentence, plain English.
keywords: [class, classes, abstract class]
contexts: [build.classes]
order: 10
---
```

Categories: `start` Getting started · `pages` Pages and dialogs · `model` Model mode · `build` Build mode · `behaviour` Behaviour · `teamwork` Sync, Git and history · `assistant` Assistant · `reference` Reference · `tutorials` Tutorials (empty index only).
