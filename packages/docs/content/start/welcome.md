MetaKit helps you build your own modelling tools and then draw models with them. Everything runs in your browser and is saved as plain files in a folder you choose.

## Where to start

1. Open or create a workspace folder.
2. Add a tool library, or build one in Build mode.
3. Create a model in Model mode.

> **Tip** Press F1 on any page to open this Help side bar. It opens at the topic for the page you are on.

See [[tutorials-index]] for step by step guides.
