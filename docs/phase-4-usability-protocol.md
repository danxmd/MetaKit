# Phase 4 usability test: a small ER Kit in under an hour

Danial runs this with one person who has not seen Build mode and does not program (a business analyst is ideal). Claude cannot run it: it needs a person. The phase is done when the task below is finished in 60 minutes or less without help from the facilitator beyond the allowed hints.

## Before

- Chrome or Edge on desktop, a new empty folder, MetaKit open on the start page. Choose the folder and create a workspace.
- Give the participant the task card below and this rule: "Think aloud. I will not say how to do things, except for the hints I may give if you are stuck for five minutes."
- Start a timer. Note the minute of every step in the results table.

## Task card

You are building a Kit for drawing entity-relationship (ER) diagrams for your team.

1. Make a Kit called "Team ER".
2. Entities are drawn as boxes with the entity name in a header. They have a name, a description (several lines) and a "Kind" that is one of Core, Support or Reference. The colour of the header follows the Kind.
3. Entities are connected by relationships. A relationship has a label and a "Cardinality" of 1:1, 1:N or N:M. Relationships are drawn as a line with a small arrow at the end, and the cardinality is printed in the middle of the line.
4. A model type "ER diagram" allows both. Add a view "Core only" that offers only the entities.
5. In the panel for an entity, the description must be on its own tab "Details". The Kind must not be editable once a description is written.
6. Make an ER diagram with three entities and two relationships, and check that it looks right.

## Hints the facilitator may give (note each one)

- Where to find the Kits list and Build mode.
- That the preview on the right shows the Kit as it is built.
- That a shape can be started from a gallery.
- That a colour can follow an attribute without writing a formula ("Colour by attribute").

## After

Ask: What was hardest? What did you expect to find and did not? Would you use this instead of drawing in a general diagram tool? Write the answers down.
