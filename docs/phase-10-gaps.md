# Phase 10: gaps found while porting tools

Every gap found while building a real tool in Build mode, with what was done about it. A gap is **fixed**, **worked around** (the tool still works, MetaKit could be better) or a **known limit**.

## Tool 1: Agent pipeline (`tools/agent-pipeline/`)

A language for pipelines where agents and humans perform tasks and create artifacts: agents, humans, tasks, artifacts, gates and stages; two views (Pipeline and Artifact lineage); a "Check pipeline" script; status commands as rules. Sample model: `code-review.mkmodel.json`. Spec: `openspec/changes/agent-pipeline-tool`.

| #   | Gap                                                                                                                                                                                                                                                  | Status                                                                                              | What was done / what is open                                                                                                                                                                   |
| --- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | The starter swimlane shape (and so BPMN lite's lane) put its rotated name in the middle of the lane. Rotation turns around the centre of the part, and the shape assumed it turned around the corner.                                               | Fixed                                                                                               | New label box centred on the strip, in `packages/shapes/src/starter.ts` and `tools/bpmn-lite/tool.json`.                                                                                       |
| 2   | A container with an opaque background hides the connectors between the objects inside it, because connectors are drawn under all objects.                                                                                                           | Worked around                                                                                       | The stage shape has a transparent background. **Open:** draw a container's background below the connectors, or warn in the shape editor. BPMN lite's lane still has a white background.       |
| 3   | A constraint written with `or` showed "Unexpected "or"" and nothing more. The formula language uses `\|\|`, `&&` and `OR()`, and people who know spreadsheets write the words.                                                                       | Fixed (message)                                                                                     | The message now says what to write instead. **Open:** accept `and`, `or` and `not` as operators.                                                                                               |
| 4   | The tool-level check (`validateToolLibrary`) does not parse constraint formulas, so a tool with a broken constraint passes and the error shows up later, on every object, in the problems list.                                                      | Worked around                                                                                       | The tool's test parses every formula in the file. **Open:** parse constraint, rule and default formulas when a tool library is validated, and show the error next to the formula in Build mode. |
| 5   | A rule with the event "command" cannot be limited to a class, so "Mark ready" for tasks also shows in the toolbar when an agent is selected. Two classes with an attribute of the same key (`Status`) make a shared command risky.                   | Worked around                                                                                       | Each command rule has an `if` on an attribute only that class has. **Open:** a `class` on the command (shown only when the selection is of that class) and a place for "when selection is".   |
| 6   | A formula on a number attribute fails with "Minus needs a number" when an operand is empty (`ActualEffort - Effort` before anyone enters an effort).                                                                                                 | Worked around                                                                                       | The tool writes `(ActualEffort ?? 0) - (Effort ?? 0)`. **Open:** decide whether empty numbers count as zero in arithmetic, or show an empty result instead of a warning on every object.       |
| 7   | Questions about the graph ("is an artifact of an autonomous agent approved by a gate?") cannot be asked in a rule or constraint without loops.                                                                                                       | Known limit                                                                                         | The "Check pipeline" script answers them. This is the kind of job scripts are for; a rule action with a relation query would be larger than the plan allows.                                  |
| 8   | The attribute panel's tabs per class are written by hand in the tool file; Build mode's panel editor was not used for this tool, so the editor was not tested with a real layout of three tabs and `visible` formulas.                              | Open                                                                                                | Open the tool in Build mode and edit the Task and Agent panels to see whether the editor handles them.                                                                                         |
| 9   | Stage totals (effort of the tasks inside a stage) were not built. `children()` exists in formulas, but a stage shape that prints a total was not tried.                                                                                              | Open                                                                                                | Try `sum(children().Effort)` in the stage shape.                                                                                                                                               |

## Found while writing the documentation

The documentation (`packages/docs/content`) was written from the code. These behaviours looked like bugs or gaps; the topics describe them as they are today. All are **Open**.

| #   | Gap                                                                                                                                                         |
| --- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| D1  | The panel setting "Show the connected relations" is stored but the Model mode attribute panel does not read it.                                             |
| D2  | The relation class editor has no help-text field, and relation classes have no panel layout button.                                                         |
| D3  | The Build form cannot edit the options of a Choice table column, so that column type is refused.                                                            |
| D4  | Tool library settings has no editor for layers or numbering.                                                                                                |
| D5  | The shape colour helper reads only the `? :` chain form, so the shipped Task shape's `if(...)` formula is not recognised.                                   |
| D6  | Renaming a key rewrites formulas, constraints, rules, shapes, looks and panel layouts, but not scripts. Renaming a class, relation class or model type changes only the key. |
| D7  | Unticking a class in a model type does not clean up its views, cardinalities or container rules.                                                            |
| D8  | Build mode Undo and Redo have no keyboard shortcut (header buttons only).                                                                                   |
| D9  | The rule action "Run a script" finds the script by its id (`scr_...`) but the field says "Name of the script" and the editor never shows ids.               |
| D10 | `BuildView` does not pass `api` to the Scripts section, so the Run button, status notes and console do not work in Build mode.                              |
| D11 | The web app's script host provides messages, confirm, prompt and choose only. `ui.form`, `ui.progress`, `files.open` and `files.save` fail, so the ER-to-SQL example cannot save a file. |
| D12 | GitLab OAuth code exists but nothing in the UI uses it.                                                                                                     |
| D13 | A Git release is applied as an undoable edit to the open tool library, not as the read-only version ADR 0007 describes.                                     |
| D14 | There is no history viewer in the app (undo, snapshots, trash, and your sync service's or Git's history stand in).                                          |
| D15 | Pasted objects always land at the top level; container membership is not copied. There is no Duplicate command.                                             |
| D16 | Refusal messages read "a Agent" and "a Artifact" (no a/an agreement).                                                                                       |
| D17 | Dialogs open with `showModal`, so the Help side bar behind a dialog cannot be clicked (F1 still toggles it).                                                |

## How to read this list

Fixed gaps are in the pull request. For the open ones, Danial decides which become work in phase 10 and which stay known limits for 1.0.
