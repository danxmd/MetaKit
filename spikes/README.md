# spikes

Phase-0 experiments. Code here is never imported by `packages/` or `apps/`; it may be copied into `packages/` later, but only through a reviewed change.

- `canvas/`: work package 0.2, Canvas 2D performance. Report: `docs/spikes/canvas.md`.
- `sync/`: work package 0.3, folder storage and merge. Report: `docs/spikes/sync.md`.
- `behaviour/`: work package 0.4, formula engine and QuickJS sandbox. Report: `docs/spikes/behaviour.md`.
- `git/`: work package 0.5, GitHub and GitLab APIs from the browser. Report: `docs/spikes/git.md`.

The gate report for all of phase 0 is `docs/spikes/phase-0-report.md`.
